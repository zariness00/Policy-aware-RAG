# IT Access Review Policy

Document type: Release notes
Policy ID: P06
Version ID: P06-v2
Effective from: 2025-01-01
Changes from: P06-v1

## Changes

- Scope: Temporary staff and interns are now covered by the IT access policy.
- Access reviews: High-risk roles must now be reviewed at least every three months; the six-month review period continues for other roles.
