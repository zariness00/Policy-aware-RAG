# Procurement Approval Policy

Document type: Release notes
Policy ID: P03
Version ID: P03-v3
Effective from: 2026-01-01
Changes from: P03-v2

## Changes

- Scope: Contractors and consultants engaged in procurement activities are now covered.
- Approval requirements: The department-head approval threshold increased from $500 to $750. The Finance Department's secondary approval threshold increased from $2,500 to $3,000.
