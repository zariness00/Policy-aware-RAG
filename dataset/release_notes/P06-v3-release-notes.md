# IT Access Review Policy

Document type: Release notes
Policy ID: P06
Version ID: P06-v3
Effective from: 2026-01-01
Changes from: P06-v2

## Changes

- Emergency access exceptions: The deadline for documenting the request and obtaining IT Director approval decreased from 24 hours to 12 hours after access is granted.
- Access request processing: The IT department's processing time decreased from three business days to two business days after supervisor approval.
